# Agent and human authority

Dusk is the shared identity and control plane for one operator and their agents.

Humans and agents have equal product authority. If a safe, proof-gated Git-backed action is available in the browser, it must also be available to agents. The reverse is equally true.

That includes opting a repository into Dusk by creating its root `dusk.md`, editing that file later, and preserving knowledge rather than refusing an opt-in on the caller's behalf.

Build these capabilities on one backend path. Do not create UI-only or MCP-only mutations. Preserve repository access checks, proof tokens, validation, proposal behavior, and explicit confirmation for destructive changes for both callers.
